A beginner-friendly Face Recognition System developed using C programming language. The project demonstrates how face-feature data can be stored, compared, and matched to identify a registered person.

Note: This is an educational simulation. It uses numerical face-feature values rather than processing real images or webcam video.

🚀 Features
👤 Register new persons
🧑 Store personal information
🔢 Store face-feature values
🔍 Search person by ID
🧠 Face-feature matching
✅ Face recognition
📋 Automatic attendance marking
🕐 Date and time logging
📊 View attendance records
🗑️ Delete registered persons
💾 Save data using files
🔄 Load saved data when the program starts
🖥️ Menu-driven console interface
🛠️ Technologies Used
Language: C
